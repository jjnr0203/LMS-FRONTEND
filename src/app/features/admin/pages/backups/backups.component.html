Respaldos del Sistema

Genera y descarga un respaldo completo de la base de datos en formato SQL.

Respaldo de Base de Datos

Al generar un respaldo se creará un archivo .sql con toda la información actual del sistema: usuarios, docentes, estudiantes, matrículas, materias y configuraciones. Este proceso puede tardar unos segundos dependiendo del volumen de datos.

  • Incluye estructura y datos completos
  • Compatible con PostgreSQL para restauración
  • Archivo con fecha y hora del momento del respaldo
